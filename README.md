# nbcom-eu Sportswear Store

A complete responsive storefront for **nbcom-eu**, a modern sportswear, activewear, footwear and fitness-accessories shop.

## Included
- 32 product cards across Men, Women, Footwear and Accessories
- Product search, category filtering and sorting
- Responsive mobile/desktop design
- Working front-end shopping bag saved with localStorage
- Customer support and product advisory contact sections
- Newsletter form interaction
- Local logo and local SVG product-image fallbacks
- Pexels-hosted product/lifestyle photography with local fallback art if a remote image is unavailable

## Open locally
Open `index.html` in a browser. For the best experience, serve the folder with any simple static web server.

## GitHub Pages
Upload the contents of this folder to your GitHub Pages repository and make sure `index.html` stays at the repository root.

## Contact numbers
The phone numbers in this demo use the U.S. `555-01xx` fictional range and should be replaced with your real business numbers before publishing commercially.

## Pricing
Catalog prices are editable sample retail prices in USD. Update them in the `window.NBCOM_PRODUCTS` data block inside `index.html` if needed.
